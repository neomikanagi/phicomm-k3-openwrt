# K3 真机验收

**当前状态：未在 K3 真机验证。** 编译通过不改写此结论；以下每项都需实际记录时间、固件 SHA-256 和结果。只操作 K3，不碰 K3C、不强刷、不猜引导器。

| 项目 | 通过标准 | 本轮结果 |
|---|---|---|
| 救援准备 | 配置/分区/校准/引导备份在电脑，已确认当前引导器的恢复方法 | 未测 |
| 刷入与启动 | 型号和分区匹配，sysupgrade 检查通过，有线启动正常 | 未测 |
| LAN / WAN | 三个 LAN 端口逐一测试、WAN DHCP；需要 PPPoE 时另测 | 未测 |
| 双频 | 同一国家、信道、客户端，WPA2 AES；重启后均可连接 | 未测 |
| 无线 A/B | official 与 ac88 在同位置比较吞吐、延迟、远端信号和掉线；包含有线 iperf3 端 | 未测 |
| 长稳 | 72 小时：无无线崩溃、OOM、非预期重启；穿插多设备和大流量 | 未测 |
| 代理 | 直连、代理 TCP/UDP、路由器自身、节点失效、停用后恢复均符合预期 | 未测 |
| DNS | AGH 启用前正常；启用后 53/5053 都解析，代理分流不回环，重启后恢复 | 未测 |
| 广告过滤 | AGH 新增临时测试域 `||k3-ad-test.example^`，客户端查询得到阻断，删规则后恢复 | 未测 |
| 客户端旁路 | 单独记录硬编码 DNS、IPv6 DNS、自带 DoH；不冒充全流量过滤 | 未测 |
| 故障回退 | `k3-adguard disable` 恢复解析；错误 YAML/无密码被拒绝，DNS 验证失败恢复旧配置 | 未测 |
| 断电重启 | 网络、WAN、双频、代理、规则下载与 tmpfs 数据重建正常 | 未测 |
| 无线回退 | official 版本可恢复；不沿用 ac88 的 overlay/blob 或不兼容旧配置 | 未测 |

每次比较均保存 `k3-check` 输出，注意它不包含完整节点配置或订阅；分享日志仍应检查 IP/MAC 等隐私。温度、无线校准、供电和散热问题无法通过更换系统保证解决。

硬件不在构建机上，因此本工程不能远程替代刷机、实物检查和以上压测。不要为追求“满速”启用会绕过透明代理的流量卸载，也不要复制未知来源的功率/校准参数。
